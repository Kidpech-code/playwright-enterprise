Testing Companion

คู่มือการใช้งานสำหรับผู้ที่ติดตั้ง Extension จาก GitHub Release เรียบร้อยแล้ว

ตั้งค่าครั้งแรก เริ่ม Session ใช้งาน Popup อ่าน Report แก้ปัญหา

1 ตั้งค่าครั้งแรก

ℹ️
ถ้าติดตั้ง Extension จาก ZIP ที่ดาวน์โหลดมาแล้ว ข้ามขั้นตอนนี้ได้เฉพาะ Extension — แต่ยังต้องติดตั้ง Local Agent ด้านล่างก่อนใช้งานครั้งแรก

สิ่งที่ต้องมี

  • Node.js 18+ — ตรวจสอบด้วย node -v
  • npm — ติดมากับ Node.js
  • Google Chrome

ขั้นตอน

1

Clone และติดตั้ง dependencies

git clone https://github.com/Kidpech-code/playwright-enterprise.git
cd playwright-enterprise
npm install
npx playwright install chromium
2

สร้างไฟล์ Environment

cp env/.env.example env/.env.staging

เปิด env/.env.staging แล้วใส่ค่า:

BASE_URL=https://www.saucedemo.com
USER_STANDARD_PASSWORD=secret_sauce
3

โหลด Extension ใน Chrome

  1. เปิด chrome://extensions
  2. เปิด Developer mode (toggle มุมขวาบน)
  3. คลิก Load unpacked
  4. เลือก folder extension/ ภายใน repo ที่ clone มา
💡
ถ้าดาวน์โหลด testing-companion-0.1.0.zip จาก GitHub Release แล้ว — Extract ZIP ก่อน แล้วเลือก folder extension/ ที่ได้มา

2 เริ่ม Manual Testing Session

1

เปิด Local Agent

เปิด Terminal แล้วรันคำสั่ง — เปลี่ยน URL เป็นเว็บที่ต้องการทดสอบ:

npm run manual:start -- --url https://www.saucedemo.com

Terminal จะแสดง:

Manual Testing Companion is running.
Target: https://www.saucedemo.com
Agent: ws://127.0.0.1:3737

Chromium จะเปิดขึ้นมาพร้อม Extension ที่โหลดไว้

2

เปิด Extension Popup

คลิก icon Testing Companion ใน toolbar ของ Chrome (อาจต้องกด icon ปริศนา 🧩 เพื่อ pin ก่อน)

Popup จะ connect ไปยัง Agent อัตโนมัติ — สถานะเปลี่ยนเป็น Recording

3

กด Start Manual Test

กดปุ่ม Start Manual Test เพื่อเริ่มบันทึก session อย่างเป็นทางการ — Agent จะจับภาพหน้าจอแรกพร้อม DOM snapshot

⏱️
ปุ่มนี้มี delay 3 วินาทีก่อน capture — ใช้เวลานี้จัดหน้าจอให้พร้อม

3 ใช้งาน Popup ระหว่างทดสอบ

ทุกปุ่มทำงานผ่าน WebSocket ส่งคำสั่งไปยัง Agent ที่รันอยู่ใน Terminal

ทันที

Phase Indicator (แถบ 4 ช่อง)

แถบด้านบน popup แสดงว่าตอนนี้อยู่ขั้นไหน:

  • Initialize — กำลังเชื่อมต่อ
  • Record — กำลังบันทึก session
  • Capture — กำลังจับภาพ
  • Stop — กำลังสร้าง report

4 อ่านและแชร์ Report

เปิด Report

หลัง Stop — popup แสดงปุ่ม Open report → คลิกเพื่อเปิด summary.html ใน browser

หรือเปิดด้วย Terminal:

open test-artifacts/session_<timestamp>/summary.html

ไฟล์ที่ได้

test-artifacts/session_2026-06-16T14-30-00-000Z/
  ├── summary.html ← รายงานหลัก เปิด browser ได้เลย
  ├── manual-session.json ← ข้อมูล session ทั้งหมด
  ├── log.json ← console logs + network errors
  ├── screenshot.png ← ภาพล่าสุด
  ├── trace.zip ← Playwright trace (เปิดด้วย show-trace)
  ├── video/
  │   └── video.webm ← วิดีโอทั้ง session
  ├── screenshots/ ← ภาพแต่ละ step
  ├── snapshots/ ← DOM ณ แต่ละ step
  └── session_....zip ← ทุกอย่างรวมไว้แชร์ได้

แชร์ให้ทีม

ส่ง session_....zip ให้ผู้รับ → Extract → เปิด summary.html ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม

5 แก้ปัญหาที่พบบ่อย

Popup แสดง "Could not connect to local agent"

Agent ยังไม่ได้รัน — กลับไปเปิด Terminal แล้วรัน:

npm run manual:start -- --url https://...

ถ้ารันแล้วยังไม่ได้ ตรวจสอบว่า URL ใน popup ตรงกับ ws://127.0.0.1:3737

ปุ่ม "Start Manual Test" เป็นสีเทา กดไม่ได้

Popup ยังไม่ได้ connected — รอสักครู่หรือกด Connect ใหม่ ถ้ายังไม่ได้ปิด popup แล้วเปิดใหม่

ไม่มีวิดีโอใน report

ต้องกด Stop & Generate Report ให้ Agent ปิด browser อย่างถูกต้อง — ถ้ากด Ctrl+C ใน Terminal ก่อนกด Stop วิดีโออาจไม่ถูก flush

ใช้ Ctrl+C ใน Terminal ได้ แต่รอ popup แสดง Report ready ก่อน

Extension icon ไม่แสดงใน toolbar

คลิก icon ปริศนา 🧩 ใน toolbar → กด pin ที่ Testing Companion

Chrome แสดง banner "Extensions are managed" ทุกครั้ง

เป็นปกติของ Developer Mode — กด ✕ dismiss ได้ ไม่ส่งผลต่อการทำงาน

⚠️
อย่าลืม: ทุก session สร้าง folder ใหม่ใน test-artifacts/ — ลบออกได้เองเมื่อไม่ใช้แล้ว เพราะไฟล์วิดีโออาจใหญ่
